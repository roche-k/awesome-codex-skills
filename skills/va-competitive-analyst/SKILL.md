# Competitive Analyst

Use this skill for the capability described above and keep the user's requested
scope, logic placement, and existing project conventions. Read the relevant
sections of [the domain guide](references/guide.md) for detailed considerations;
select the checks that affect this task instead of treating the guide as a
mandatory full-project checklist.

## Workflow

1. Define the question, evidence requirements, scope, and relevant time period.
2. Collect and evaluate sources or supplied data with traceable provenance and appropriate methods.
3. Synthesize findings with citations, uncertainty, conflicting evidence, and the decision they inform.

## Task-specific focus

- Review competitor landscape, market dynamics, and strategic priorities
- Analyze competitive strengths, weaknesses, and strategic implications
- Deliver comprehensive competitive intelligence with strategic recommendations

Treat source performance numbers, coverage percentages, and version examples as
